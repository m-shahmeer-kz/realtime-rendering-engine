Real-Time Rendering Engine

Every Bitcoin price on Bitstamp, one per minute from 2012 to 2025: 6,847,200 points, drawn live by a C++ engine compiled to WebAssembly and rendered with WebGL 2. Scroll or pinch to zoom, drag to pan, double-click to reset.

How it works: a min/max pyramid finds, for every pixel column, the first, last, lowest and highest price (the M4 method), so the GPU draws a few thousand points instead of millions, with the same picture. Zoom in far enough and it switches to candlesticks. Data: Zielak, "Bitcoin Historical Data", Kaggle (CC BY-SA 4.0), via ff137/bitstamp-btcusd-minute-data. Code: GitHub.
